                          常见问题排除


Q1: ImportError: No module named 'timm'
A: 需要安装 timm 库: pip install timm

Q2: RuntimeError: CUDA out of memory
A: DeiT-Tiny 应该在 CPU 上也能运行，检查可用内存

Q3: PNNX 工具找不到
A: 需要在 tools/ 目录放置 pnnx 可执行文件或使用完整路径

Q4: ../imgs/car.jpg 不存在
A: 脚本会自动使用 torch.randn() 生成随机张量，测试不会中断

Q5: CSV 文件格式不对
A: 脚本使用 np.savetxt，格式为 '%.6f'，逗号分隔，平展数据


                           技术细节


DeiT-Tiny 模型规格:
  - 参数量: ~5.7M
  - 输入: (1, 3, 224, 224)
  - 输出: (1, 1000) logits
  - 推理延迟: ~100ms (CPU) / ~10ms (GPU)

ImageNet 预处理标准:
  - Mean: [0.485, 0.456, 0.406]
  - Std:  [0.229, 0.224, 0.225]
  - 原因: 基于 ImageNet 统计的归一化参数

CSV 数据格式:
  - 单行存储
  - 高精度: 6 位小数
  - 分隔符: 逗号 ','
  - 用途: 跨语言数据交换（Python → C++）
